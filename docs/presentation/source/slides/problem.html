Why this server

An escalation factor is only as good as its paper trail

What the analyst needs

Defensible inputs

Series that match the scope, weights and periods the analyst owns, and a factor anyone can recompute later.

Without the server

Plausible numbers

It recalls series IDs from memory, types index values in, and averages quarters that BLS never published.

What this server does

Cited numbers

Every index level comes from a pinned snapshot, and every answer cites each series, its weight, the periods and the snapshot ID.
