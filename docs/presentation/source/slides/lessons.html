Lessons learned

What the first runs taught us

Test the test user

The scripted user missed real model phrasing and ended 23 of 25 early episodes.

Strict schemas teach

A model invented fields (keywords, class, year) that were silently accepted.

Errors must say how to recover

20 of 29 tool errors were “PPI” or “ECI” where pc or ci was required.

Make the order visible

Models calculated before saving the spec, and never validated unprompted.

Measure the guardrails

They held under weak agents: 26 of 27 checks in the worst run.

Fingerprint everything

Fingerprints exposed a recorder bug that mislabelled later runs.

All six come from docs/EVALUATION_JOURNEY.md, section 4, each with its evidence there. The point for judges: the evaluation changed the code. Series validation was hardened (commit 188b298), the recorder was fixed (PR #19), and the scripted user was widened, all before any model was judged again. Lessons 2 to 4 are still open as tool changes (extra="forbid", recovery hints in error text, a single goal-level calculate tool), and they appear in future work. The timeline of these phases is in Appendix A5.
